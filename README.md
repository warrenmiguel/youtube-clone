# YouTube Clone 📺

A responsive YouTube homepage clone built using **HTML5** and **modern CSS**, developed as a self-learning project after completing the html & css course by supersimpledev.

## 🚀 Features
- **Responsive Video Grid:** Automatically adjusts layout columns using CSS Grid based on screen width (mobile, tablet, desktop viewports).
- **Pure-CSS Expandable Sidebar:** Features a custom smooth-sliding sidebar and content layout transition triggered entirely through CSS (using the checkbox hack) without relying on JavaScript.
- **Header Navigation:** Includes a fixed navigation bar with search inputs, voice search buttons, hover tooltips, and interactive notification badges.
- **Component-Based Styling:** Organized with modular CSS architecture (`header.css`, `sidebar.css`, `video.css`, `general.css`).

## 🛠️ Techniques & Concepts Learned
- **Nested Layouts Technique:** Structuring components inside containers to manage complex section layouts.
- **Display Properties:** Utilizing `block`, `inline-block`, and `flex` to control element flow and positioning.
- **CSS Grid:** Building fluid, multi-column responsive grids for video card layouts.
- **CSS Flexbox:** Aligning items and spacing navigation elements effortlessly.
- **CSS Position:** Managing fixed headers, absolute timestamps, and tooltips (`position: fixed`, `absolute`, `relative`).

## 💻 Built With
- HTML5
- CSS3 (Flexbox & Grid)
